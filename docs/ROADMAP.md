# Phase gates

P0: local privacy pipeline and deterministic tests (this branch).
P1: Palantiny JSONL adapter, real-world scan-quality calibration.
P2: Ed25519 signed reports, durable outbox, libp2p bootstrap and pub/sub.
P3: replay-safe regional indexer, independent nodes, coarse location registration.
P4: live heatmap with delayed, multi-node cell suppression.
P5: security, accuracy, robustness and adversarial review.
P6: incentives only after trustworthy measurements and Sybil mitigations.

Palantiny upstream: https://github.com/narasim-teja/palantiny

Keep network code in this repository. Propose a narrow local event hook upstream
only after the maintainer agrees. No remote access to Palantiny's personal data.
